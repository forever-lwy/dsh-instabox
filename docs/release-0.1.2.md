# 0.1.2

当前对话可以直接观看和接管所用云机，不必先切到独立 Instabox 页面。

## 展示

- 默认在最新消息末尾出现云电脑卡片；也可在设置切换为原生右侧栏标签。
- 使用时自动展开只读画面，支持观看、放大和主动接管。
- 本轮使用结束后，自动观看画面收成入口按钮；手动观看及人工接管不会被自动收起打断。
- 收起后仍可再次观看或接管。收起人工控制时先交还，避免隐藏的交互连接继续持有控制权。
- 右侧栏使用原生追加标签接口，保留官方其他标签与内容。

## 关联和生命周期

Host 仅按工具执行时的真实会话记录云机活动；跨会话、跨机器的任务结果保持原归属。状态与当前 turn/agent 运行状态关联，避免工具步骤之间不断展开和收起。

观看和接管由浏览器插件级控制器持有，消息组件卸载仅移除呈现。切换会话、收起和插件卸载负责清理，后台 Host 的持久接管记录仍覆盖断线与重启恢复。桌面链接继续按完整 URL 和观看模式重建 iframe，保留 0.1.1 的只读权限修复。

新配置 desktopPlacement 缺省为 inline，旧设置自动补默认值。设置切换立即影响当前预览。没有自动安装、升级或重启日常 DSH。
