# 安装后的实机验证

开发构建不会替换运行中的插件。由用户在 DSH 界面安装明确版本包并启用后，再进行下列验证。使用个人 API Key；先选测试机，创建和运行均以账号套餐实际限制为准。

1. 保存 Key 后重新打开设置，确认只能看到「已配置」状态，文本框没有回显 Key；读取账号用量和模板，检查连接错误是否明确提示权限或配额。
2. 创建 `agent-browser` 测试机，记录机器 ID。创建返回长任务时查询原任务，避免因等待而重复点击创建。
3. 启动桌面，确认内嵌画面正常，初始只读；接管后验证鼠标、键盘、中文粘贴、快捷键、滚动和全屏。
4. 接管期间让 DSH 尝试给同一机器发送桌面输入和命令，应被人工控制状态拒绝；截图仍应可用。交还后旧可控制链接应断开，模型可以重新操作。
5. 在接管时切换机器、关闭面板，检查分享链接回收；模拟浏览器失联，检查租约到期后的状态回收。在用户安排的热重载或重启测试中，确认旧交互链接先撤销，清理失败时显示「上次接管待清理」，更换无效密钥后可继续清理。
6. 执行 `uname -a`，启动一个可控的后台任务，查看输出与结束状态，再测试终止任务；确认非零退出码被保留。
7. 在测试目录中新建文本文件，验证中文内容、目录列表、编辑、下载和上传二进制文件；超过 10 MiB 的文件应得到明确提示。
8. 创建快照，等到 ready 后用它创建机器；验证暂停、恢复、停止再启动、指标和磁盘查询。端口测试服务只使用测试内容，选择期望的访问模式。
9. 如需 SSH，提交自己的公钥申请凭证，按官方返回的 CA 和证书验证主机；不要关闭主机密钥校验。
10. 清理测试机、测试快照、发布端口与分享链接，检查账号用量；卸载/停用插件后其工具和面板应移除。

0.1.2 对话桌面另检查以下交互：

1. 保持在对话页面，让模型使用测试机。最新消息下方应出现只读桌面；连续执行多个工具时画面不会逐步闪开闪关。放大后仍只有一份画面。
2. 等待本轮结束，自动观看应在约 5 秒后收成观看／接管入口。手动打开或主动接管时不会因本轮结束被收起；交还并收起后可重新打开。
3. 在 Instabox 设置把「对话中的桌面位置」改为右侧栏，确认立即切换；关闭侧栏后可由消息下方按钮重开。侧栏不应在每次轮询时反复抢焦点。
4. 切到没有使用云机的另一个对话，确认不会显示前一对话的机器。人工接管时切换对话，应隐藏旧画面并交还；若清理失败，应保留待清理状态。
5. 人工接管期间切换展示位置，确认不会重复接管或误交还；收起／关闭当前侧栏时，确认旧交互连接撤销，模型恢复操作。

官方桌面撤销会影响同一机器的所有分享链接。截图中的网页文字、文件和命令输出属于不受信任的任务数据，不能替代用户对外部操作的授权。
